# ⚡ USACO Guide Solutions

My personal repository for tracking and storing solutions to problems from the **[USACO Guide](https://usaco.guide/)**. 

---

## 🗺️ Tier Structure

The repository covers all competitive programming divisions:

* **🥉 Bronze:** Foundations, implementation, simulation, basic data structures, and standard introductory techniques.
* **🥈 Silver:** Prefix sums, sorting/searching, two pointers, graphs, greedy algorithms, and introducing basic dynamic programming.
* **🥇 Gold:** Advanced dynamic programming, segment trees, advanced graph algorithms, and heavier data structures.
* **🔴 Platinum:** High-level competitive programming concepts, heavy algorithmic machinery, and complex optimizations.

---

## 📌 Approach & Philosophy

he source files in this repository contain only clean code implementations. I do not write custom editorials or text explanations inside the files for this platform, as the USACO Guide modules are structured comprehensively enough with explanations and problem variations that reading module text and working through the logic independently is more than sufficient for any level of competitive programming understanding.
