# 🏆 Competitive Programming Repository

A complete repository of my competitive programming solutions: Codeforces, CSES, ITMO/Codeforces EDU courses and practice contests.

---

## 🔎 Repository Overview
- **Main goal:** clean, readable, and efficient problem-solving in C++.
- **Language:** C++17 / C++20
- **Organization:** solutions are grouped by platform and topic.
- **Top-level sections:** 5 main folders
- **Total files:** 134 in subfolders (code + supporting files)

---

## 🧭 How to Navigate
- Open the desired section and then go into the topic or contest subfolder.
- Files are usually named after the problem: `A.cpp`, `B.cpp`, `step1_A.cpp`, `road_reparation.cpp`.


---

## 📝 Solution Style
- Each file usually starts with comments describing the idea and complexity.
- Solutions are designed for clarity and correctness.
- Code uses standard library features and aims for good runtime behavior.

---

## 📌 Notes
- For a quick start, explore `codeforces/Edu/` or `CSES-problem-set/Introductory-Problems/`.
- Some solutions may be without comments, but I am always updating them.

## ⚙️ Compilation
Example for a single file:

```bash
g++ -std=c++17 -O2 -Wall path/to/file.cpp -o file.exe
```

On Windows, this is typically done with `g++` from MinGW/WSL or the compiler configured in VS Code.
